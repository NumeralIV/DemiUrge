# art/ - original 3D assets for DEMIURGE (Blender -> Unreal)

Everything here is generated by scripts from the concept reference sheets, so it can be rebuilt bit for bit and
needs no downloads or licences. The full pipeline (conventions, materials, LOD rules, the towns factory hook,
AssetLab) is documented in `docs/lab/asset-pipeline.md`.

```
blender -b --factory-startup --python art/tools/make_textures.py            # art/textures/<set>/T_*.png (+ manifest.json)
blender -b --factory-startup --python art/tools/build_asset.py -- shrine     # art/export/shrine/*.fbx, art/shrine/shrine.blend
blender -b art/shrine/shrine.blend --python art/tools/render_preview.py -- art/renders/blender
UnrealEditor-Cmd <project>.uproject -run=pythonscript -script=art/tools/ue_import.py -unattended -nosplash
bash UnrealLab/AssetLab/renders.sh                                         # judged renders -> art/renders/ue/
```

| folder | contents |
|---|---|
| `tools/` | the scripts (dmtex, make_textures, dmkit, shrine, build_asset, render_preview, contact_sheet, ue_import) |
| `textures/` | tileable PBR sets (BC sRGB, N OpenGL, ORM linear) and their manifest (tile size in metres, albedo check) |
| `shrine/` | `shrine.blend`: every part of the 9 configs x 3 LODs as separate objects, plus the joined export copies |
| `export/shrine/` | `SM_Shrine_<Config>[_LOD1/_LOD2].fbx` (UCX collision on LOD0) and `shrine.manifest.json` |
| `renders/blender/` | Cycles previews (reference-sheet framing) and contact sheets |
| `renders/ue/` | AssetLab renders: golden hour, storm and night at 40 m, 300 m and 1 km beside the generated stand-in |
