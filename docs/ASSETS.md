# DEMIURGE — asset standard (binding for every asset engineer)

Real 3D assets replace the generated stand-ins for close-up views. Many engineers build assets
at the same time, so everything below is fixed. If `docs/lab/asset-pipeline.md` (the shrine
engineer's write-up) disagrees with this file, **this file wins**; the lead reconciles.

## 1. Rules
- **$0 extra spend** (owner): original work in Blender 5.2, procedural textures, CC0 inputs you record, and
  **AI-generated textures from Google Flow** (owner decision, 2026-11-19: "use flow wherever it makes sense";
  the owner's subscription, 0 credits per image). Flow images live in `art/textures-flow/` with a provenance
  file each (tool, model, date, prompt, account) and are processed by `art/textures-pilot/make_maps.py`
  (seam healing, light flattening, normal, roughness, AO, ORM). Use them for tileable surface materials;
  keep procedural or original work where generated images cannot be controlled (UV-specific painting,
  decals that must match geometry). Pilot and rules: `art/textures-pilot/README.md`.
- **Reproducible:** every asset is generated by a Blender Python script you own
  (`art/<family>/build_<family>.py`), run headless:
  `"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --python <script> -- <args>`.
  The script writes the `.blend` source and the exports. Never hand-edit an export.
- **Visual targets** are the approved concepts in `docs/concept/` (settlements, landmarks,
  wonders, units, nature, shrine). Read the `index.md` of each for shapes, materials and hex colours.
- **Fidelity for the game camera:** buildings are seen from about 40 m to 2 km, units and
  animals at 20 to 60 px tall. Model silhouette, roof shape, proportion and material response
  well; do not spend triangles on detail nobody sees. Close-up views (40 m) must still hold up.

## 2. Conventions
| Item | Rule |
|---|---|
| Units | 1 Blender unit = 1 metre. Unreal imports at 100x (centimetres). |
| Axes | Z up, front faces −Y in Blender (Unreal +X forward after import with the standard FBX settings). |
| Pivot | Centre of the footprint at ground level (Z = 0). Units: centre at ground level. |
| Ground | Buildings include a plinth or foundation that extends 0.3 m below Z = 0 so they sit on sloped terrain. |
| Names | `SM_<Family>_<Asset>_<Variant>` (meshes), `M_<Family>_<Material>` / `MI_<Family>_<Material>_<Culture>`, `T_<Family>_<Texture>_<D|N|ORM|M>` (diffuse, normal, packed occlusion-roughness-metallic, mask). Families: `Age0` … `Age6`, `Wonder`, `Ship`, `Unit`, `Animal`, `Prop`, `Tree`, `Shrine`. |
| LODs | LOD0 full, LOD1 ~40 % triangles, LOD2 ~12 %, LOD3 a simple hull or a card for anything over 10 m. Screen sizes 1.0 / 0.35 / 0.12 / 0.04. |
| Triangle budgets (LOD0) | House 2–6k, civic building 8–20k, wonder 30–80k, ship 3–15k, vehicle 1–4k, person or animal 300–800, prop 50–1k. |
| Materials | At most 3 slots per mesh: `Structure`, `Roof`, `Detail`. Culture variation by material instances (tint, roughness) and a few roof or ornament mesh variants, never by duplicating whole buildings. Night windows: emissive mask in the `M` texture channel R. |
| Textures | 1024² per set (2048² for wonders), PNG, sRGB for D only. Trim sheets shared within a family are encouraged. |
| States | Buildings that can be damaged: `_Intact`, `_Construction`, `_Damaged`, `_Ruin` on the same footprint (`_Burnt`, `_Drowned` for the families the shrine pioneered when cheap). |
| Exports | FBX (binary, smoothing groups on, tangents) to `art/<family>/export/`; one file per mesh including its LODs. |
| Manifest | `art/<family>/manifest.json`: per mesh name, footprint (m), height (m), triangles per LOD, materials, textures, states, culture variants, licence (`original`), script that made it. |

## 3. Preview and checks (no Unreal needed per asset)
- Render previews in Blender with `art/tools/preview_rig.py` if it exists, otherwise a rig in your
  own script: sun at 20° elevation warm (golden hour), a cool sky fill, neutral ground; views at
  40 m three-quarter, 300 m oblique and 1 km oblique; EEVEE, 1280×720.
  Save to `shots/asset-<family>-<asset>-<view>.png` and look at every image.
- **GPU and CPU are shared by up to 40 agents.** Run every render and every Unreal launch through
  the slot tool so at most 5 heavy jobs run at once and none starts while the GPU is above 80 % or the CPU above 70 % (owner's limits):
  `python "<root>/tools/render_slot.py" -- <command and args>` (it waits for a free slot).
- Check: scale against a 1.8 m figure, pivot at ground, normals out, no non-manifold holes in
  closed parts, UVs inside 0–1 without overlaps for baked maps, triangle counts within budget.

## 4. Into Unreal (later, by the lead's integration agent)
The towns, nature and units modules select meshes through their factory functions (read
`Unreal/Source/Demiurge/Game/Towns`, `Nature` and the units code; do not edit them). Your
manifest is what the integration agent uses to map sim building types, ages, tiers and cultures
to your meshes, so make it complete.

## 5. What goes into git
Only the generator scripts, `manifest.json` and `README.md` of each family are versioned. Everything
the scripts produce (`.blend`, exports, textures, previews) is rebuilt from them and ignored by git, so
keep every script runnable from a clean checkout.
